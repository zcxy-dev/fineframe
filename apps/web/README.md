# Web page

One page in front of [`pnpm edit`](../../packages/engine/README.md#editing-footage): drop footage and music in, choose the length, the aspect and a style, press start, watch the progress, then play the finished video and download it with its captions.

```bash
mise run start      # or pnpm start, with mise activated
```

`pnpm start` at the repository root ([`scripts/start.ts`](scripts/start.ts)) checks Node, pnpm and uv, says what to install when one is missing, warns when the disk has less than 10 GB free, runs `pnpm install` and `uv sync` in `worker/`, builds the page when its code or the packages it uses changed, starts the server and opens http://127.0.0.1:3000 in the browser (`pnpm start --no-open` leaves the browser alone). When the page already runs there, it only opens it; another program on the port is named as the problem. Ctrl+C stops the server. `mise run start` does the same where only mise is installed, installing the pinned Node, Python and uv first. `pnpm -C apps/web build` and `pnpm -C apps/web start` still build and start the page alone.

- **Address:** the server listens on 127.0.0.1 only. `VIDEO_EDITOR_HOST` and `PORT` change that, such as `VIDEO_EDITOR_HOST=100.x.y.z` for a private network; the page has no accounts, so never put it on a public address. Requests addressed to any other name are refused, so another site cannot reach the page by resolving its own name to this machine; `VIDEO_EDITOR_ALLOWED_HOSTS` adds names, comma-separated, for a proxy in front such as `tailscale serve`, without changing the address.
- **Desktop app:** the [desktop app](../desktop/README.md) runs this page in its own window, with its server on a free loopback port. There, the server keeps the keys in the app's own folder and installs the analysis's Python environment on its first start (`VIDEO_EDITOR_SETUP=1`), showing the download in the page; an edit cannot start until it is installed.
- **Inputs:** videos, still images and audio files, dropped as files or whole folders or chosen with a picker. Videos are cut and stills can show as B-roll. Audio files (by their extension, as `pnpm edit` sorts them) are music, passed with [`--music`](../../packages/engine/README.md#editing-footage): Claude picks the track that fits, or none, and the done page names the one the video plays. "Don't use" beside a track leaves it out. Music needs the licence it is used under, such as CC0 1.0, typed once for every track and passed as `--music-license`; use only music you have the right to use. The length is a preset (15 s, 30 s, 1 min, 3 min, 10 min) or typed, from 15 s to 1 h; the aspect is 9:16, 1:1 or 16:9; the style is one of the engine's [looks](../../packages/engine/README.md#colour) or none; names and terms, one per line, help the speech model spell them; visuals are rich, Claude's B-roll for each point (motion-graphics cards, web pages, stock footage and logos, beside the speaker or full frame, with soft sound effects), or minimal, none of it, passed as `--visuals`.
- **Speech:** heard on this computer, or on OpenRouter ([`--asr cloud`](../../worker/README.md#cloud-speech)) with the owner's OpenRouter key. A computer with too little memory for the local speech model ([how much](../../README.md#install)) starts on OpenRouter, and the page says why; either can be chosen.
- **Jobs:** each edit gets a folder in `~/.cache/video-editor/jobs/` (`VIDEO_EDITOR_JOBS` moves it), outside the repository. Files stream into it; a name that could leave the folder, a hidden file, a file of another type, a file larger or smaller than announced, and footage that does not fit the free disk space are refused. The footage is deleted when the next edit is created; the outputs stay.
- **One edit at a time:** a second is refused while one runs, before its footage is sent, as one analysis already takes the machine's memory. Requests from another site are refused. Stopping the server stops a running edit.
- **Progress** comes from the command's JSON lines, sent to the page as Server-Sent Events: the stage, a bar that never goes back, and the latest message. What an edit downloads on its first use shows its own bar with the bytes, the percentage and the time left at its rate so far: the analysis's models (the speech model, its aligner and the audio tagger; 3.5 GB in all on a CPU), FFmpeg, and Chrome Headless Shell and Remotion's compositor for the effects. The job's id is in the page's address, so a reload or a bookmark opens it again; a running edit keeps going with the page closed.
- **Outputs:** the video plays in the page; MP4 and SRT downloads, and with B-roll, the credits of the stock footage, icons, screenshots and sound effects it shows (`<name>.broll.txt`).
- **Keys:** with no Anthropic API key, the page asks for one when it opens, and "API key saved · Replace" in its header replaces it; with speech on OpenRouter and no OpenRouter key, it asks for that one. Free [Pexels](https://www.pexels.com/api/) and [Pixabay](https://pixabay.com/api/docs/) keys, for stock footage with rich visuals, are optional and added under the visuals setting; without them, B-roll comes from cards and web pages. The server checks a key at no cost, by looking up the planning model with Anthropic, reading the key's own details with OpenRouter, or searching once for a clip with Pexels or Pixabay, and saves only a key its service accepts, in the git-ignored `.env` at the repository root (`VIDEO_EDITOR_ENV_FILE` moves it; the desktop app keeps it in its own folder), written whole with permissions 0600 (on Windows, an access list that keeps out the machine's other users) and its other lines kept. A key goes to its service and to `pnpm edit`, and never back to the page or into a log. A key saved there is used over `ANTHROPIC_API_KEY`, `OPENROUTER_API_KEY`, `PEXELS_API_KEY` or `PIXABAY_API_KEY` in the server's environment, which counts when the file has none. An edit without the keys it needs is refused before its footage is sent.
- **Cost:** before an edit, the page estimates what Claude will cost from the footage's length and the edit's, fitted to the [measured edits](../../packages/engine/MEASUREMENTS.md#edit-measurements); after it, what planning and the cut checks cost at list price, from the command's done line. A failed edit says what it cost before it stopped.
- **Fixable failures** say what to do: no key or a key Anthropic or OpenRouter refuses (with a button to replace it), an account out of credit, a full disk (also checked before the footage is sent), a file that cannot be read, and no connection.
